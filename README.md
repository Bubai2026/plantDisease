## Project Overview
Plant diseases are a major cause of crop loss worldwide, and early detection is one of the most effective ways to prevent it. This project builds a complete image classification pipeline to automatically detect plant diseases from a single leaf photo.

The project covers:

- Exploratory Data Analysis (EDA) on the PlantVillage dataset
- Image preprocessing and augmentation
- A baseline CNN built from scratch
- An improved CNN with Batch Normalization, Dropout, and L2 regularization
- Transfer learning using MobileNetV2, ResNet50, and EfficientNetB0
- Fine-tuning the best-performing model (EfficientNetB0)
- Model evaluation and comparison (Accuracy, Precision, Recall, F1-score, Confusion Matrix)
- Explainability using Grad-CAM
